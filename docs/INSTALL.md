# Chrome / Edge 安装与更新

要求 Chromium 134 或更高版本。已实际验收 Chrome 152 和 Edge 152。浏览器版本可在「关于」页面查看。

## 加载扩展

1. 保留一个固定的安装目录。可以直接使用源码项目中的 `dist/`，或将 `BookMarker-1.1.0.zip` 解压到独立文件夹。
2. Chrome 在地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json` 的文件夹**。不要选择项目源码根目录、ZIP 文件本身或它的上层文件夹。
5. 找到 BookMarker。可以在浏览器的扩展菜单中固定图标，然后点击图标打开工作台。

扩展会读取当前浏览器配置中的书签。第一次整理前，可先使用「整理工具 → 导出与备份 → 完整项目备份 ZIP」保存一份独立备份。

## 权限

| 权限 | 用途 | 申请时机 |
| --- | --- | --- |
| `bookmarks` | 读取与修改浏览器书签、监听外部变化 | 安装时 |
| `storage` | 保存本地设置 | 安装时 |
| `unlimitedStorage` | 保存原件、操作日志、快照和检测数据，减少常规配额限制 | 安装时 |
| `alarms` | 唤醒后台，继续未完成任务与每日备份 | 安装时 |
| `webRequest` | 观察本扩展检测请求的跳转和浏览器原始网络错误 | 首次点击检测时 |
| HTTP / HTTPS 网站访问 | 从后台跨域请求待测 URL | 首次点击检测时 |

如果拒绝检测授权，管理、导入、导出、回收站和版本功能仍可使用。缺少权限的检测项会显示「已跳过」。下次主动开始检测时可以再次授权。

扩展没有 `storage.sync`、`proxy`、`scripting`、`history` 权限，也没有内容脚本。安装后不会自动检测所有书签。

## 更新

将新版本文件放在**原安装目录**，在扩展管理页点击「重新加载」。从源码更新时先执行 `npm ci` 和 `npm run package`。重新加载后刷新工作台标签页。

保留原目录与扩展身份有助于继续使用已有本地数据库。不要通过卸载再安装来更新；卸载会清除该扩展的 IndexedDB 和设置。下载的项目 ZIP 不受影响。

## 常见安装问题

- **无法加载 / 找不到清单**：检查选择的目录中是否直接存在 `manifest.json` 和 `background.js`。
- **版本太旧**：升级到 Chromium 134+。
- **界面提示“扩展安装预览”**：当前打开的是 Vite 或普通 HTML 页面，请从扩展图标打开工作台。
- **后台未响应**：在扩展页重新加载扩展并刷新工作台，查看扩展的 Service Worker 检查窗口。操作日志不会因普通后台重启丢失。
- **企业策略禁止开发者模式**：需要使用组织允许的安装方式；本版本没有商店发布包。

首次手动安装时，建议确认浏览器显示的可选权限弹窗与上表一致，再按实际需求允许或拒绝。
