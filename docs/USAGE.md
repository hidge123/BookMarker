# 使用与错误诊断

## 书签管理器

首次打开使用图标视图，显示浏览器顶层目录。以后恢复上次有效目录、视图和显示排序。目录只展示直接子项，单击选择，双击进入文件夹或打开书签。前进、后退恢复目录、搜索和可见位置；上一级和底部路径栏可以直接导航。当前目录被外部删除时，退回最近仍可用的祖先目录。

图标视图只显示图标与名称；项目右键「显示属性」打开可编辑弹窗。列表视图显示名称、网址、创建时间和类型，右侧默认展示所选项目属性。切换视图保留目录、选择和可见位置。多选时右侧提供批量操作。

顶部基础搜索按名称或 URL 包含匹配，不区分大小写，默认搜索当前目录及子目录。清空搜索回到目录浏览。结果右键「在书签管理器中显示」进入其真实目录并选中；选中搜索结果时，底部路径显示真实位置。

### 选择与文件式操作

- Cmd/Ctrl 点击多选，Shift 点击连选；从空白区域拖动框选，靠近上下边缘会自动滚动。框选包含尚未渲染的项目。
- 「新建」菜单或空白区右键可创建文件夹、书签。新建和粘贴在后台完成后选中结果。
- Cmd/Ctrl+X 剪切后显示半透明，进入目标目录按 Cmd/Ctrl+V 才移动；Esc 取消剪切。工作台内部剪贴板在跨目录浏览时保留，刷新页面后清空。
- Cmd/Ctrl+C、Cmd/Ctrl+V 复制书签或完整目录子树，生成新 ID，保留来源元数据引用，不继承检测结果。同名顶层副本追加「副本」「副本 2」等，子目录名称和顺序不变。复制可通过操作记录撤销、重做。
- 单项 F2 就地重命名，Enter 保存、Esc 取消；多项 F2 或「重命名」显示批量预览。支持字面替换、前后缀和连续编号。
- 目录图标、侧边栏、底部路径和当前目录空白处均可接收拖放；普通树节点也可拖动。悬停目录约 600 毫秒后进入，侧边栏悬停展开子目录。
- 拖到项目边缘显示插入线。支持首尾和多项插入，保留源项目相对顺序；搜索或非浏览器排序时只能移入目录。父子同时选中只处理最外层节点；禁止移入或复制到自身及子目录。
- 输入框继续使用原有文本编辑快捷键，不会触发全库选择、剪切或删除。Alt+左/右为后退/前进，Alt+上为上一级，Cmd/Ctrl+K 聚焦搜索。

「整理工具」收纳移动、重命名、导入、导出、刷新和排序。普通排序只改变显示；只有明确点击「将当前排序应用到浏览器」才修改浏览器顺序。

反馈分为「已提交」「已完成」「部分完成」。剪切仅移除后台确认成功移动的项目，失败项留在剪贴板，可核对冲突后重新剪切或重试；详细原因见「操作与版本」。

## 数据看板

书签总量、检测覆盖、异常数量和重复组指标可以点击筛选结果。高级搜索默认全库，可组合目录（含子目录）、名称/URL、域名、类型、检测状态和重复条件。选择结果后，右侧可查看 HTTP 状态、错误原文、跳转和检测时间。结果的「在书签管理器中显示」进入真实目录；重新点击「数据看板」恢复此前筛选、选择和滚动位置。

「重复处理预览」仅对当前筛选结果的完整 URL 精确分组。`http` 与 `https`、不同参数、不同锚点均视为不同 URL。预览列出每项来源路径、保留项、将回收的副本；只读项目保留。确认只提交预览列出的可写副本，不扩展到筛选范围外。预览之后的外部修改仍接受后台冲突检查。

「检测链接」可检查选中结果（含子目录）、指定范围目录、全库，或重测当前看板筛选中的失败项。任务显示进度，可取消，关闭管理页面后继续由后台执行。

## 回收与版本

- 普通删除会将节点移动到来源顶层书签区域内按需创建的「BookMarker 回收站」。这是浏览器可见的真实文件夹。
- 恢复会使用保存的原父目录和位置，保留节点 ID。原目录丢失、不可写或仍在回收站时，恢复到同一区域的可写根目录，并显示提示。
- 永久删除和清空要求勾选确认。永久删除无法保留原 ID、创建时间及 API 未公开数据，因此没有“无损撤销”。
- 「操作与版本」逐步显示完成、失败、冲突、等待核对；批量操作不是数据库事务，不保证整批原子性。
- 撤销/重做由新的操作记录完成。撤销新建项会移入回收站，重做再移回，以保留节点 ID。
- 版本回滚逆序撤回快照之后本工具已确认的操作，不整库删除重建。外部修改会保留为冲突。
- 每 50 次完成操作、大型批次（20 步及以上）及永久删除/回滚前自动快照；每天另存一份，保留最近 30 份每日快照。手动快照和操作日志不自动清理。
- 当前修改尚未完成或等待核对时，下一次修改与手动快照会暂停提交，以维持清晰的版本边界。

## 中断后的核对

后台重启先读取未完成日志，再对照浏览器实际数据。

1. 更新/移动若已达到预期状态，记录为完成；若仍是修改前状态，可继续执行。
2. 无法确认的新建会显示「需要核对」，**不会自动再建一次**。查看该步骤的目标目录、标题、URL，并在详情查看可能对应节点的 ID。
3. 确实已创建时，输入该节点 ID 并选择「关联此节点」；后台仍会验证目录、标题和 URL。
4. 确认该步骤应跳过时，选择「核对后跳过」。跳过不会删除任何已有节点；依赖该目录的后续新建会明确失败。

不要用重复点击提交来代替核对。出现外部冲突时，先刷新并检查实际书签，再针对当前节点发起新的修改。

## 导入、备份与恢复

从「整理工具 → 导入」进入。支持 Chrome/Edge/Firefox 导出的 HTML、Chromium `Bookmarks` JSON、Firefox 未压缩 JSON。Firefox `.jsonlz4` 请先从 Firefox 导出 HTML。先预览项目数量和目录，再确认在所选目录中建立一个新的导入文件夹。

原文件按原始字节保存并计算 SHA-256。未知字段、标签、图标、注释和高精度数字保留在原件或扩展元数据中；浏览器 API 只写入支持的标题、URL 和结构。URL 可能被浏览器规范化，实际值显示在详情中，原始输入仍在备份中。

HTML 导出为 UTF-8，排除回收站。完整项目 ZIP 包含：

- `project.json`：API 可见书签树、元数据、历史、快照、任务、结果、设置及原件索引。
- `originals/<来源ID>`：每份导入文件的精确字节；文件名、格式和 SHA-256 见索引。
- `README.txt`：备份格式说明。

导入项目 ZIP 时先校验原文件哈希，再预览。即使在同一个配置内，也采用创建新节点的恢复方式，不把旧 ID 当作写入目标。回收站标记和原目录位置映射到新节点；原目录缺失时使用当前导入区域。旧历史、快照和检测证据完整归档在导入的 ZIP 原件中，不将另一配置的撤销记录或检测状态激活为当前数据。需要查看旧版本时，可解压该原件阅读 `project.json`；要在原配置撤回本工具操作，使用「版本快照 → 回滚预览」。

单个输入文件最大 128 MiB，最多 200,000 个节点，JSON 目录深度最多 100 层。文件和备份通过 IndexedDB 暂存传输，避免把原始字节塞入 Chrome 的 JSON 消息。大文件解析、ZIP 压缩及完整历史读取仍受本机内存、磁盘与浏览器性能影响。

## 网页检测

在数据看板选择选中项目、指定目录、全部书签或筛选范围内失败项重测。默认总并发 6、同主机最多 2、单次尝试超时 12 秒。先 HEAD；对于 400/403/404/405/406/501 使用 GET 复核，发送 `Range: bytes=0-65535`，用 BYOB 字节流累计读取最多 64 KiB 后取消正文。在不支持限定读取的流上，取得响应头后直接取消正文。网络栈可能提前缓冲数据，不能据此承诺线路上的总传输量严格只有 64 KiB。

| 状态 | 含义 |
| --- | --- |
| 正常 | 实际收到 2xx 响应 |
| 站点响应错误 | 实际收到 404、410、5xx 等 HTTP 响应 |
| 访问受限 | 401、403、429，可能是登录、权限或限流 |
| 连接异常 | 浏览器提供了实际网络错误原文，例如 `net::ERR_EMPTY_RESPONSE` |
| 无法确认 | 超时、缺少详细错误，或证据不足 |
| 已跳过 | 内网筛选、非 HTTP/HTTPS、URL 中含凭据、权限不足、取消或 URL 已变 |
| 结果已过期 | 当前节点 URL 与被测 URL 不一致 |

请求不携带站点 Cookie 或登录凭据，故登录后的可访问页面可能被标为访问受限。遵循浏览器适用的网络配置，不设置代理。默认跳过明确私有 IP、回环、链路本地、已知内网域名等；这不是严格的网络隔离，无法在请求前可靠识别所有 DNS 解析结果，也不能保证重定向不会指向内网。

队列每一短批和每个完成结果都会持久化。关闭工作台标签页不取消任务；关闭浏览器会停止执行，下次启动后通过启动事件、消息和 30 秒 alarms 继续。明确点击取消会持久保存取消状态；已发出的请求可能已经抵达站点。

超时、DNS 或连接错误不能直接确定责任在本地还是目标站点。没有可关联的浏览器错误时显示「未提供详细错误」，不编造错误码，不依据检测结果自动删除。
