# BookMarker 修改计划：Finder 风格管理器与统一数据看板

## 1. 概要与默认行为

将现有“所有书签、链接检测、重复书签”三个栏目，调整为 **“书签管理器”和“数据看板”两个入口**。

书签管理器承担日常文件式整理；数据看板集中提供链接检测、重复处理和高级检索。继续使用现有 Chromium 扩展架构，所有修改即时写入浏览器，复用已有回收站、日志、恢复和备份能力。

默认采用图标视图，首次打开显示浏览器顶层目录，后续恢复上次有效目录和视图。目录浏览只显示直接子项。

## 2. Finder 风格书签管理器

### 布局与显示

| 区域 | 修改内容 |
|---|---|
| 左侧栏 | 书签管理器、数据看板、文件夹树；底部保留回收站、操作与版本、设置。 |
| 顶部工具栏 | 前进／后退／上一级、当前目录名称、基础搜索、新建、整理工具、图标／列表切换。导入导出收纳到工具菜单。 |
| 中央区域 | 当前目录内容，占据主要空间；移除宣传文案、大标题和统计卡片。 |
| 底部路径栏 | 可点击、可接收拖放的面包屑，以及项目数量和选中数量。 |

参考 Finder 的浅灰侧栏、紧凑工具栏、蓝色文件夹和列表交替行底色，提高文字及选中状态的清晰度。

- **图标模式**：只显示图标和名称，不显示域名、日期、检测状态或右侧属性栏。右键“显示属性”打开可编辑的属性弹窗。
- **列表模式**：显示名称、网址／域名、创建时间和类型；右侧默认展示所选项目属性，多选时展示批量操作。无选择时显示简洁提示。
- 两种视图共用选择和操作状态，切换时保留目录、选中项和可见位置；属性展示方式随视图切换。
- 前进／后退恢复目录、搜索和滚动位置；侧边栏自动展开当前目录的祖先。目录被外部删除时退回最近可用祖先。

### 基础搜索

- 顶部仅提供名称或 URL 的文本包含匹配，不区分大小写。
- 默认搜索当前目录及子目录；清空搜索恢复目录浏览。
- 搜索结果支持定位到所在目录，选中结果时底部展示其真实路径。
- 域名、状态、重复条件和跨范围组合筛选统一放到数据看板。

### 文件式操作

| 操作 | 实现行为 |
|---|---|
| 打开与选择 | 单击选择，双击文件夹进入、双击书签打开；支持 Cmd/Ctrl 多选、Shift 连选和空白区框选。 |
| 拖入目录 | 支持主区域文件夹、侧边栏文件夹、底部面包屑和当前目录空白区。 |
| 拖拽排序 | 项目间隙显示插入线，支持首尾位置和多项移动，保持选中项目的相对顺序。 |
| 拖拽导航 | 悬停文件夹约 600 毫秒后展开／进入；靠近边缘自动滚动。普通树节点也能作为拖动源。 |
| 剪切／粘贴 | 剪切后半透明显示，进入目标目录粘贴才移动；Esc 取消。 |
| 复制／粘贴 | 复制书签或完整文件夹子树；生成新节点，不覆盖或合并已有同名项目。 |
| 重命名 | 单项 F2 就地编辑，Enter 保存、Esc 取消；多项进入批量重命名预览。 |
| 空白区右键 | 新建文件夹、新建书签、粘贴、全选、排序和视图切换。 |
| 项目右键 | 打开、剪切、复制、复制网址、移动、重命名、移入回收站、显示属性。 |

补充规则：

- 使用工作台内部剪贴板，跨目录导航保留；粘贴前校验来源。剪切只清除已成功移动的项目，失败项保留。
- 同名复制的顶层项目追加“副本”及递增编号，子树名称和顺序保持不变；副本不继承检测结果。
- 父子同时选中时只处理最外层节点；禁止移动或复制到自身及后代目录。
- 默认显示浏览器原始顺序。其他排序仅改变显示，另提供明确的“将当前排序应用到浏览器”。
- 搜索、筛选或非浏览器顺序下允许移入目录，禁用含义不明确的插入排序。
- 输入框保留原有快捷键；新建和粘贴完成后选中结果，刷新不无故跳回顶部。

## 3. 统一数据看板

采用“概览指标＋高级筛选＋结果表／详情”的布局，不再分别建立检测、去重和高级检索页面。

- **概览指标**：书签总量、检测覆盖情况、异常数量和重复组数量；点击指标直接筛选下方结果。
- **高级检索**：默认全库，可选择目录及子目录；组合名称／URL、域名、类型、链接状态和重复条件。
- **链接检测**：支持选中结果、指定目录及全库检测，展示任务进度、取消、失败项重测、HTTP 状态、原始错误及跳转信息。
- **重复处理**：按完整 URL 精确分组，展示来源路径、保留项及将回收的副本，确认后提交现有回收操作。
- **定位管理**：结果提供“在书签管理器中显示”，进入真实目录并选中目标；返回看板时恢复筛选和滚动位置。

检测沿用现有权限申请、后台续跑、错误分类和过期结果规则。去重只处理预览明确列出的可写副本，不隐式扩大到范围外数据。

## 4. 实现与接口调整

- 将现有主界面拆为管理器、数据看板及共享属性组件；网格和列表共享导航、选择、剪贴板及拖放控制。
- 新增 `ExplorerState`、`ClipboardState`、`DropIntent`，分别管理目录与视图、待粘贴项目，以及统一的移动／插入意图。
- `EditCommand` 新增 `copy`，后台将校验后的源子树展开为现有创建步骤，复用日志、中断核对、撤销和重做。
- `move` 增加可选目标节点锚点，由后台校验并计算插入位置；保留旧 `index` 调用兼容。
- 复制保留扩展来源元数据引用；新节点使用浏览器生成的 ID 和时间，原件保持不变。
- 操作反馈区分已提交、已完成和部分失败；剪切状态、结果选择等以后台完成结果更新。
- 网格按可见行虚拟化，列表完善现有虚拟化；框选依据布局坐标计算，不能只选择已渲染的 DOM。
- 目录、视图和排序偏好使用现有本地存储；保持数据库、项目备份及旧操作记录兼容，不新增扩展权限。

## 5. 实施顺序与验收

按“布局与双视图 → 导航及选择 → 拖放与剪贴板 → 数据看板整合 → 回归验证”实施。

重点验收：

- 图标模式默认没有属性展示，右键可打开属性；列表模式默认显示右侧所选项目属性。
- 顶部只有基础搜索和管理工具，面包屑固定在底部并支持导航、拖放。
- 不借助侧边栏即可完成新建目录、框选、拖入、打开、重命名和返回。
- 移动保持节点 ID；复制嵌套目录保持结构与顺序，原件不变，副本可撤销。
- 验证多项插入、空目录落放、悬停导航、边缘滚动、非法目标和输入框快捷键。
- 普通显示排序不触发浏览器写入；后台中断、外部修改和部分失败不会导致重复创建或误覆盖。
- 检测、去重和高级检索在数据看板完成，定位管理后能够返回原看板状态。
- 以现有 63 项单元测试为回归基线，补充新交互测试；在 Chrome／Edge 独立配置中验证一万条数据下的双视图、搜索和框选。
- 完成类型检查、生产构建和集成回归，更新操作说明、截图及可安装扩展包。
